# Tech stack

Python/Flask/SQLAlchemy/React,MaterialUI

# Running the web application

`npm install`

`npm start`

# Running the backend

`flask run` or `flask --app filename.py run` if not named `app.py` or `wsgi.py`

`flask run --debug`


# Activating virtual environment

`. .venv/bin/activate`

# Modifying the database file

`sqlite3 foo`
